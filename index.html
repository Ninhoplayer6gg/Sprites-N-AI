Dados para a engine
Como usar no seu jogo
  1. Exporte em 1×: é o tamanho real dos pixels. Aumente depois, na engine.
  2. Godot: arraste o PNG para o projeto e crie um AnimatedSprite2D. Em SpriteFrames, use Adicionar quadros de uma spritesheet com as colunas e linhas dos dados acima. Deixe o filtro de textura em Nearest.
  3. Unity: importe o PNG, mude Sprite Mode para Multiple e Filter Mode para Point. No Sprite Editor, corte por Grid By Cell Size com a largura e a altura do quadro.
  4. GameMaker e Construct: use a opção de importar uma tira ou spritesheet e informe colunas, linhas e o tamanho do quadro.
  5. Cada linha da spritesheet é uma animação. No personagem a ordem é: parado, andar, atacar e dano, cada uma virada para baixo, esquerda, direita e cima.
